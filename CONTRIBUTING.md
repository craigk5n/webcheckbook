# Contributing to WebCheckbook

Thank you for considering contributing! We follow standard open-source best practices.

## Code Style
- PHP: Follow PSR-12 standards (indent with 4 spaces, no tabs).
- SQL: Use uppercase for keywords, lowercase for identifiers.
- CSS: Consistent indentation; use classes for styling.
- Comments: Keep existing comments; add new ones for clarity.
- No modifications to comments unless they're incorrect after changes.
- Ensure code works in PHP 8+ and is mobile-friendly.

## Pull Requests
- Base PRs on `main`.
- Describe changes in the PR title/description.
- Test locally (e.g., with XAMPP or Docker).
- Do not add dependencies without discussion (app must remain self-contained).

## Issues
- Use GitHub Issues for bugs/features.
- Provide steps to reproduce for bugs.

## Development Setup
- Clone and set up as per README.md.
- Use a local MySQL instance for testing.

Happy coding!
